# my-sms
my-sms est une application de chat web épurée, semblable à WhatsApp, conçue exclusivement pour discuter entre amis. Sans fil d'actualité ni fonctionnalités superflues, la plateforme se concentre sur l'essentiel : des conversations privées, directes et sans distractions. C'est l'alternative idéale pour rester connecté simplement.
